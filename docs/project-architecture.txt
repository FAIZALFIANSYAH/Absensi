PRINSIP PENGGUNAAN
==================================================

- Pisahkan halaman dan controller berdasarkan role: admin, teacher, student.
- Pisahkan logika bisnis inti ke Actions atau Services, jangan ditumpuk di controller.
- Gunakan Enums untuk role, approval status, attendance status, dan submission status.
- Gunakan Middleware + Policies untuk kontrol akses.
- Pertahankan Components/ui untuk komponen dasar, lalu buat komponen domain terpisah.
- Untuk fitur user management, pusatkan operasional admin di area Admin/Users lalu tetap delegasikan logic ke Action/Service.
- Struktur ini dipilih agar selaras dengan BRD: approval akun, QR code siswa, scan absensi, kelas, materi, tugas, dan submission.
